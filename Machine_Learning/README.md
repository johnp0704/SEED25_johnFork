Logistic Regression:
    Steps:
        1. Run "LogReg_test.py" to both test and evaluate the model

Logistic regression (with kfolds cross validation):
    Steps:
        1. Run "KFolds_Validation.py" to both train and evaluate the model

XGBoost:
    Steps:
        1. Run "train_xgboost.py" to train the model
        2. Run "eval_xgboost.py" to evaluate the model

YOLO:
    Steps:
        1. Run "trainYOLO_model.py" to train the model
        2. Run "testYOLO_model.py" to evaluate the model

Detr:
    Steps:
        1. Run "train_detr_dandelions.py" to train the model
        2. Run "testDETR_model.py" to evaluate the model
        3. Run "DETRbounding_boxes.py" to generate bounding boxes on given images
